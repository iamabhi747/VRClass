VRClass is an immersive virtual classroom application built in Unity. It enables teachers to host interactive sessions in a realistic 3D environment with avatar-based presence. Features include shared PPT and 3D model projection, personal hologram screens for students, and support for realistic avatar movement synced via webcam (TODO). In development: hand-raising, screen sharing, and photo-based avatar generation
